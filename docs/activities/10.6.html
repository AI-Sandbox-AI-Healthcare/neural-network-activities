A recursive network builds one vector for a whole input by repeatedly merging two child vectors into a parent, from the leaves up to the root, always with the same rule. In language, the tree comes from grammar (a parse tree). Could a recursive network also handle stock prices or images?

Takeaway
  • One rule, shared by every node: h = tanh(W[hleft; hright] + b) merges two children into a parent, from the leaves up to the root. Like an RNN sharing weights across time, sharing W lets one network handle trees of any size and shape.
  • The shape of the tree matters. A chain is an RNN: x⁽¹⁾ goes through n − 1 merges. A balanced tree needs only ⌈log₂ n⌉ (6 instead of 63 for 64 leaves), so gradients cross far fewer merges (Goodfellow §10.6).
  • The tree must come from somewhere: exact for code (the compiler's syntax tree), predicted for sentences (a parser) and images (merging segments), or imposed and fixed (days → weeks → months).
  • Stock prices and images: both are possible. Images get a real tree from their segments (Socher et al., 2011). Prices only get an imposed one, which shortens paths but adds no knowledge about the data.

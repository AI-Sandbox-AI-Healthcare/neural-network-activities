Activity 10.3Bidirectional RNNs — Reading Both Ways✓ 10.3 Completed

Is "Teddy" a person? In "Teddy Roosevelt was president" yes, in "Teddy bears are on sale" no — and the word that decides comes after it. A normal RNN's output at step t has only seen the past. A bidirectional RNN adds a second RNN that reads the sentence right to left, so each output can use both sides.

Q1 Which inputs can the output o⁽ᵗ⁾ depend on — one direction vs. two?
Q2 How is the backward state computed, and in which order?
Q3 What does reading both ways cost?

Stage 3 — Write the Equations

The forward RNN is the one from 10.1.2:  h⁽ᵗ⁾ = tanh(bh + Wh·h⁽ᵗ⁻¹⁾ + Uh·x⁽ᵗ⁾). Complete the backward state and the output.

g⁽ᵗ⁾ = tanh( bg + · g⁽⁾ + · x⁽ᵗ⁾ )
o⁽ᵗ⁾ = c + · h⁽ᵗ⁾ + · g⁽ᵗ⁾
Choose from the forward weights (Wh, Uh, Vh) and the backward ones (Wg, Ug, Vg).
Takeaway
  • Two RNNs, opposite directions: h⁽ᵗ⁾ = tanh(bh + Whh⁽ᵗ⁻¹⁾ + Uhx⁽ᵗ⁾) reads left to right; g⁽ᵗ⁾ = tanh(bg + Wgg⁽ᵗ⁺¹⁾ + Ugx⁽ᵗ⁾) reads right to left, starting from g⁽τ⁺¹⁾ = 0.
  • The output combines both: o⁽ᵗ⁾ = c + Vhh⁽ᵗ⁾ + Vgg⁽ᵗ⁾ (the same as V·[h⁽ᵗ⁾; g⁽ᵗ⁾] with the two states concatenated), so every output depends on the whole input sequence.
  • The two directions never feed each other; they meet only at the output.
  • Cost: about twice the recurrent parameters, and no output until the whole sequence has arrived — fine for tagging a finished sentence, not for live, word-by-word output.

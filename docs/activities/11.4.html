Random search trains every configuration to the end, even hopeless ones. Successive halving trains many configurations briefly and keeps only the best. Hyperband runs successive halving several times, in brackets that each balance many short runs against a few long ones differently. With max_iter = 1000 and eta = 10, how many times does the code below call random_hyperparameters()?

Q1 How does successive halving spend its budget, and what can go wrong?
Q2 How many configurations does each bracket start, and with how many iterations?

from math import log, ceil
max_iter = 1000   # iterations for a fully trained configuration
eta = 10          # keep the best 1/eta at every rung
logeta = lambda x: log(x) / log(eta)
s_max = int(logeta(max_iter))
B = (s_max + 1) * max_iter

for s in reversed(range(s_max + 1)):                       # one bracket per s
    n = int(ceil(int(B / max_iter / (s + 1)) * eta ** s))   # configurations to start
    r = max_iter * eta ** (-s)                              # iterations each, first rung
    T = [random_hyperparameters() for i in range(n)]
    for i in range(s + 1):                                  # successive halving
        n_i = n * eta ** (-i)
        r_i = r * eta ** i
        losses = [run_then_return_val_loss(r_i, t) for t in T]
        T = [T[j] for j in argsort(losses)[:int(n_i / eta)]]

Takeaway
  • Successive halving trains many configurations briefly and keeps the best 1/η at every rung: 27 epochs instead of 81 in Stage 1. It assumes early losses rank configurations the way final losses would, and slow starters like C are dropped.
  • Hyperband hedges that bet by running brackets s = s_max, …, 0. Each spends about B iterations, starting n = ⌈⌊(s_max + 1)/(s + 1)⌋·ηs⌉ configurations at r = max_iter·η−s iterations. Bracket s = 0 is plain random search.
  • On paper, max_iter = 1000 and η = 10 give 1000 + 100 + 20 + 4 = 1124 calls.
  • As written, the code makes 113 calls, because int(2.9999999999999996) = 2. When you trace code, trace what the machine computes, and use integer arithmetic for counts like s_max.

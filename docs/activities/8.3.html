Stage 1 — What does momentum do?
Momentum = inertia

The velocity vector v remembers past gradients. Each step is a weighted mix of the current gradient and everything that pushed you before.

Consistent → accelerate

When gradients repeatedly point the same direction (g₁ and g₃ both push −y), velocity accumulates and steps grow larger in that direction.

α controls memory

α=0.5: half past velocity survives each step. The −ε·g term injects current gradient. Larger α = longer memory, stronger accumulation.

Activity 9.1Convolution — Sliding a Pattern Detector✓ 9.1 Completed

A dense layer gives every pixel its own weight for every output. A convolutional layer is far more economical: it learns one small grid of weights — a kernel — and slides it across the whole image, computing a weighted sum at every position. This lesson builds the idea in four steps: compute a convolution by hand, see what kernels respond to (and design one), work out the output size, then scale up from one kernel to a full layer.

Stage 4 — From One Kernel to a Conv Layer
Channels and many kernels

So far: one grayscale image, one kernel, one output map. Real layers differ in two ways:

Input channels. A colour image has 3 channels (red, green, blue). A kernel covers all of them at once — it is k × k × Cin — and still adds everything into one number per position.

Many kernels. A layer has Cout kernels, each with its own bias. Each kernel makes one output map, so the layer outputs Cout channels — like having all three kernels from Stage 2 at once.

parameters = (k · k · Cin + 1) · Cout
e.g. 8 kernels of 5×5 on a grayscale image: (5·5·1 + 1)·8 = 208
Stacking layers: how much does one output see?

Two 3×3 convolutions in a row (stride 1, no padding). Click a cell in layer 1 or layer 2 to see which input pixels it depends on — its receptive field.

Takeaway
  • One output number is the kernel multiplied element-by-element with one patch and summed. It is large when the patch is bright under the positive weights and dark under the negative ones.
  • Kernels respond to patterns: the vertical-edge kernel fires where brightness changes from left to right, the horizontal-edge kernel where it changes from top to bottom, and both give 0 on flat regions. In a CNN, training learns the kernel weights.
  • The same kernel slides everywhere: few weights (parameter sharing), and shifting the input shifts the output the same way (translation equivariance), except near the borders.
  • Output size per dimension = ⌊(n + 2p − k) / s⌋ + 1, the number of places the kernel fits.
  • A real layer has (k·k·Cin + 1)·Cout parameters, whatever the image size. Each 3×3 layer you stack widens the receptive field by 2: 3 → 5 → 7…

You are training an image classifier for categories: chair, tree, leopard, cheetah, etc. You also have a taxonomy: leopard is a large cat, a large cat is a mammal, etc. How could you design a regularizer that takes advantage of this hierarchy?

Why Use a Taxonomy?
Cross-entropy is hierarchy-blind
Standard loss treats confusing leopard with cheetah the same as confusing leopard with chair. But these are not equally wrong!
Hierarchy = similarity
Classes close in the tree should have similar predicted probabilities. A leopard image is somewhat like a cheetah — the model should reflect that.
Free knowledge distillation
In KD, a teacher provides soft labels encoding class similarity. A taxonomy gives you those relationships for free — without needing a pre-trained teacher.
The Design Challenge
You need a regularization term Ω(p) that:

1. Is zero when related classes have similar probabilities.
2. Grows when related classes have very different probabilities.
3. Uses the taxonomy distance to weight how much each pair matters.

As you work through the stages, you'll build exactly this regularizer step by step.

Q2 — Penalty Formula

We want to penalize when close classes have different probabilities. The best penalty term for a pair (i, j) is:

We want something that is 0 when probabilities are equal and grows as they diverge.
The Regularizer Formula
Ω(p) = Σ(i,j) wij · (pi − pj)²
where wij = 1 / d(i, j)

• Pairs with distance 2 → weight 0.500
• Pairs with distance 3 → weight 0.333
• Pairs with distance 6 → weight 0.167

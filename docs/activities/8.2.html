Converging → ‖∇J‖ → 0  ·  But the curve shape reveals what landscape you're navigating.
Stage 1 — Why track gradient norm?
It's your speedometer

‖∇J‖ = 0 means completely flat — no information. ‖∇J‖ large means very steep terrain. It's the only scalar that tells you how hard the optimizer is working per step.

Different landscapes, different curves

Each loss landscape feature — bowl, elongated valley, plateau, cliff edge — leaves a characteristic fingerprint on the gradient norm over time.

Core debugging skill

Logging ‖∇J‖ during training lets you distinguish healthy convergence from saddle-stalling, ill-conditioning oscillation, or cliff-induced explosion.

Stage 2 — The 4 gradient norm fingerprints
Ill-conditioned Hessian

The loss surface is an elongated ellipse — steep in one direction, shallow in another. GD overshoots the steep wall and bounces back. Gradient norm oscillates up and down without steadily decreasing.

Local Minimum

The optimizer is settling into a bowl with positive curvature in all directions. Gradient norm decays monotonically toward 0 as it approaches the bottom.

Saddle Point

Optimizer approaches from a descending direction — norm falls. Then stalls near 0 for many steps (flat saddle), before SGD noise eventually pushes it away (tiny rise).

Cliff

Optimizer walks on flat terrain then suddenly crosses into extreme curvature. Gradient norm spikes 10–100× in a single step, then drops (or the model diverges).

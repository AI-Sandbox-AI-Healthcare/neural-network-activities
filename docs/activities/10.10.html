Both GRU and LSTM gate memory — but through different equations. Identify each architectural "dimension" separating them, then explore the 2⁴ variant space.

Stage 1 — The Two Architectures Side by Side

Review both sets of equations. Notice what each architecture has that the other lacks.

GRU (3 update equations)
rt = σ(Urht−1 + Wrxt) ← reset gate
zt = σ(Uzht−1 + Wzxt) ← update gate
h̃t = tanh(Uh(r⊙ht−1) + Whxt) ← candidate
ht = (1−z)⊙ht−1 + z⊙h̃t ← output (no cell state)
LSTM (6 update equations)
ft = σ(Ufht−1 + Wfxt) ← forget gate
it = σ(Uiht−1 + Wixt) ← input gate
ot = σ(Uoht−1 + Woxt) ← output gate
gt = tanh(Ught−1 + Wgxt) ← candidate (no reset!)
ct = f⊙ct−1 + i⊙gt ← cell state
ht = o⊙tanh(ct) ← output (uses cell state)

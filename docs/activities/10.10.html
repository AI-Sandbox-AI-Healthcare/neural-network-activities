Activity 10.10GRU vs LSTM — Gates as Learned Memory✓ 10.10 Completed

In 10.7 a single weight w decided how long a linear RNN remembers, and it is fixed once training ends. Gated RNNs replace it with gates: numbers between 0 and 1 that the network computes at every step, so it can decide when to keep, write or clear its memory. The LSTM and the GRU do this with different gates.

LSTM (Goodfellow §10.10.1)
f⁽ᵗ⁾ = σ(bf + Ufx⁽ᵗ⁾ + Wfh⁽ᵗ⁻¹⁾) forget gate
g⁽ᵗ⁾ = σ(bg + Ugx⁽ᵗ⁾ + Wgh⁽ᵗ⁻¹⁾) input gate
q⁽ᵗ⁾ = σ(bq + Uqx⁽ᵗ⁾ + Wqh⁽ᵗ⁻¹⁾) output gate
s̃⁽ᵗ⁾ = tanh(b + Ux⁽ᵗ⁾ + Wh⁽ᵗ⁻¹⁾) candidate
s⁽ᵗ⁾ = f⁽ᵗ⁾⊙s⁽ᵗ⁻¹⁾ + g⁽ᵗ⁾⊙s̃⁽ᵗ⁾ cell
h⁽ᵗ⁾ = q⁽ᵗ⁾⊙tanh(s⁽ᵗ⁾) output
GRU (Goodfellow §10.10.2)
u⁽ᵗ⁾ = σ(bu + Uux⁽ᵗ⁾ + Wuh⁽ᵗ⁻¹⁾) update gate
r⁽ᵗ⁾ = σ(br + Urx⁽ᵗ⁾ + Wrh⁽ᵗ⁻¹⁾) reset gate
h̃⁽ᵗ⁾ = tanh(b + Ux⁽ᵗ⁾ + W(r⁽ᵗ⁾⊙h⁽ᵗ⁻¹⁾)) candidate
h⁽ᵗ⁾ = u⁽ᵗ⁾⊙h⁽ᵗ⁻¹⁾ + (1 − u⁽ᵗ⁾)⊙h̃⁽ᵗ⁾

U multiplies the input and W the previous state, as in Goodfellow. Many papers write i, o, c for the input gate g, the output gate q and the cell s. Libraries differ on whether u or 1 − u multiplies the old state. Goodfellow writes σ for the candidate; most implementations, and this page, use tanh.

Stage 2 — The GRU: One Gate to Keep and Write

The GRU has no separate cell: h⁽ᵗ⁾ = u⁽ᵗ⁾·h⁽ᵗ⁻¹⁾ + (1 − u⁽ᵗ⁾)·h̃⁽ᵗ⁾. A single number u decides how much to keep, and 1 − u is how much gets written. Same candidates; set u.

Stage 5 — What Matters in Practice

Many variants of these gates have been tried. Goodfellow §10.10.2 reports two large studies.

Takeaway
  • Gates are per-step weights between 0 and 1. The LSTM keeps (f) and writes (g) separately: s⁽ᵗ⁾ = f⊙s⁽ᵗ⁻¹⁾ + g⊙s̃⁽ᵗ⁾, so its cell can hold, overwrite or even add up its inputs. The output gate q decides how much of tanh(s) to show as h.
  • Along the cell, ∂s⁽ᵗ⁾/∂s⁽ᵗ⁻¹⁾ = f⁽ᵗ⁾: the w from 10.7, now set by the network at every step. Near 1 it remembers and the gradient survives; near 0 it forgets.
  • The GRU ties keep and write together (u and 1 − u), has no separate cell or output gate, and uses a reset gate r to shape the candidate. That is 3 blocks instead of 4: 45,300 vs 60,400 parameters for n = 100, m = 50.
  • In practice (Greff et al., 2015; Jozefowicz et al., 2015; both discussed in Goodfellow §10.10.2), the forget gate and the output activation are critical, coupling the gates costs little, and a forget-gate bias of 1 helps a lot. Neither design wins on every task.

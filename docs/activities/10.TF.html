The transformer computes attention with no sense of order. Explore why sinusoidal PE works, then evaluate four alternative strategies for making transformers position-aware.

Stage 1 — The Permutation Problem

Click each ordering below to see that the attention heatmap is identical — the model has no concept of position.

Click an ordering to see its attention heatmap
Key observation

Attention scores depend only on token content (Q·K dot products), not on position. Rearranging the same tokens produces the same heatmap.

This is permutation invariance — a fundamental property we must break to use order-sensitive language.

Stage 4 — Relative Positional Encoding

Relative PE injects position into attention scores as a function of token distance: scoreij = qi·kj/√d + b(i−j).

Stage 5 — ALiBi: Attention with Linear Biases

ALiBi subtracts m|i−j| from attention logits before softmax (m is a head-specific slope). No position vectors are added to the input.

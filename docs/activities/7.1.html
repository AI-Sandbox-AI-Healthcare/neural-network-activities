Why Regularization?
Simpler = Safer
Models that memorize training noise fail on new data. Regularization adds a cost for complexity.
L1 vs L2
L1 uses absolute values — drives small weights to exactly 0 (sparsity). L2 uses squared values — shrinks all weights proportionally.
The Trade-off
J̃ = J + α·Ω. A high penalty can flip the winner — a model with smaller weights may win despite worse data fit.
Hint Before You Start
Notice that w_b = [0, 3, 0] has two zero weights — it only uses feature x₁. Under heavy regularization, this sparsity is rewarded.

Meanwhile, w_a = [−2, 3, 1] uses all three features. The weight 3 will be especially costly under L2 (it contributes (3)² = 9).

Key Takeaway
  • No regularization → Model A wins (lower MSE — fits the data better).
  • L1 regularization (α=1/3) → Model A still wins — its fit advantage outweighs the extra L1 cost.
  • L2 regularization (α=1/3) → Model B wins! The −2 weight costs 4/3 ≈ 1.33 in L2 alone. Squaring amplifies large weights disproportionately.

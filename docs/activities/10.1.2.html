Stage 4 — What Is Shared, What Is Switched Off
Takeaway
  • h⁽ᵗ⁾ = f(W·h⁽ᵗ⁻¹⁾ + U·x⁽ᵗ⁾): the memory term W·h⁽ᵗ⁻¹⁾ and the input term U·x⁽ᵗ⁾ are added, then passed through the activation (Goodfellow uses tanh and a bias b).
  • Order matters: the same inputs in a different order give a different state ([5, 0] vs [1, 2]), and the same x⁽²⁾ gives different states depending on what came before.
  • Parameter sharing across time: W and U are reused at every step, so the model has the same 8 numbers for 2 steps or 100.
  • A ReLU zero silences a component for one step; the next pre-activation can turn it back on.

Someone has given you 1000 instances to construct a model. You want to use early stopping as your regularization strategy. How will you use the data? When will you stop training? How much data can you train on?

Why Early Stopping Works
Training loss always decreases
Given enough epochs, a model can fit training data arbitrarily well. But that's not generalization — it's memorization.
Validation loss is the signal
A held-out set you never train on tells you when the model stops generalizing. Its loss dips then rises — stop at the dip.
The catch: you can't use all 1000
To have a validation set, you must set aside some data. You literally cannot train on everything if you want to use early stopping.
The Core Tension
More training data → better model fit.

But you need some data withheld for validation to know when to stop.

Early stopping forces a trade-off: train on less, but know when to quit.

What's the Split For?
Train set: model learns from these — weights are updated on each example.

Validation set: checked after each epoch to see if generalization is improving.

Test set: touched only once at the very end to report final performance honestly.
Key insight: Early stopping uses validation loss as its stopping signal. Without validation data, there's no signal — you'd be guessing.

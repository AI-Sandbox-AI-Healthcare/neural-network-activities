Activity 9.3Adaptive Pooling — A Fixed Output Size for Any Input✓ 9.3 Completed

Your CNN ends in a dense layer that expects exactly 4 numbers per channel. But photos arrive at many different sizes. Ordinary pooling uses a fixed window, so its output grows and shrinks with the input — and the dense layer no longer fits. Adaptive pooling flips the idea: you fix the output size, and the windows adapt to the input.

Stage 3 — Adaptive Pooling: Fix the Output, Let the Windows Adapt

Now you choose the output length T. The input is split into T regions of about n / T values, and each region is max-pooled. Region t starts at ⌊t·n / T⌋ and stops just before ⌈(t+1)·n / T⌉. Change n: the regions stretch, but the output length stays T.

Stage 4 — Adaptive Pooling in Real CNNs

With T = 1 there is a single region, the whole channel: global average pooling turns every channel into one number, its mean. Many CNNs (for example ResNet) use it right before their final dense layer.

Takeaway
  • Pooling summarizes each window by its maximum (or mean). It ignores small shifts that stay inside a window — but a shift across a window boundary still changes the output.
  • With a fixed window k and stride s, the number of outputs ⌊(n − k) / s⌋ + 1 grows in steps with n, so a fixed-size dense layer cannot follow it.
  • Adaptive pooling fixes the output length T and splits the input into T regions of about n / T values each (neighbours share a value when n / T isn't whole).
  • Global average pooling (T = 1) makes the dense layer's size independent of the image size — at the price of throwing away where each feature was.

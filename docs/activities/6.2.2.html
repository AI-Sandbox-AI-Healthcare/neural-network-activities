Activity 6.2.2 Sigmoid Cross-Entropy Cost ✓ 6.2.2 Completed

The sigmoid cross-entropy cost unifies both y=0 and y=1 into a single formula using a sign flip (1−2y). The softplus function ζ(z) = −log σ(−z) describes how cost grows — near zero when the model is correct, large when it is confidently wrong. Activity 6.2.3 n Sigmoid Units vs Softmax(n) ✓ 6.2.3 Completed

Both produce n outputs in (0, 1) — but they behave fundamentally differently. Sigmoid units are independent: each output has its own gate, and changing one leaves the others unchanged. Softmax outputs compete: boosting one always suppresses the rest, because all outputs are forced to sum to exactly 1.

pk = σ(ak) = 1 / (1 + e−ak)

Stage 5 — The Three Questions, Answered
Q1 — What loss do we actually care about?

Detection quality: did the model find all the cats, draw accurate boxes, avoid false positives, and avoid duplicates? Precision, recall, IoU, and mAP all measure pieces of this. In short: actual goal = good detections — high recall + high precision + accurate boxes.

Q2 — Can or should we optimize it directly?

Not usually. mAP, precision, recall, and exact detection correctness involve thresholds, ranking, and matching predictions to ground truth — decisions that aren't smooth, differentiable operations. Gradient-based training needs losses that give gradual feedback, not thresholds and sorts.

Q3 — What surrogate loss should we use instead?

A blend of easier-to-optimize pieces: classification loss ("is this a cat?"), box localization loss ("how close is my box to the true box?"), and objectness/confidence loss ("is there an object here at all?"). Minimizing these nudges the model toward the real goal.

Takeaway
  • In object detection, we care about real detection quality: finding all the cats, drawing accurate boxes, and avoiding false detections.
  • Real evaluation metrics like mAP are hard to optimize directly — they involve thresholds, ranking, and matching that don't have useful gradients.
  • So we train with a surrogate loss: classification loss + box localization loss + objectness/confidence loss.
  • The surrogate loss guides training, but final evaluation should still use the real detection metric.

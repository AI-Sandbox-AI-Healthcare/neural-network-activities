Stage 1 — Why can't you optimize the true detection metric?
True metric ≠ trainable

mAP, IoU, precision@threshold all involve sorting, thresholding, and set operations — discrete steps with zero or undefined gradients.

Flat regions kill training

When a predicted box misses entirely, IoU = 0 and ∂IoU/∂W = 0. The gradient carries no information about which direction to move.

Surrogates are smooth proxies

We choose differentiable functions that correlate with the true goal. Minimize the surrogate during training; report the real metric at test time.

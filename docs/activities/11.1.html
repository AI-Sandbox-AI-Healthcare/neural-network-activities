A hospital's cancer registrars read every clinical note to find the ones that describe a cancer case, which must then be added to the registry. About 5% of notes do. You are building a model that flags notes for them to read. It should save them reading, but every missed case leaves the registry incomplete.

Q1 Why can a model be 95% accurate and still useless here?
Q2 Which metric, at which threshold, matches the registrars' goal?
Q3 What do the registrars actually gain, and what target should you set before training?

Takeaway
  • Accuracy hides a rare class: with 5% cancer notes, flagging nothing scores 95%. The accuracy-best threshold here (0.65) still misses 93 of 500 cases.
  • Recall = TP / (TP + FN) counts the cases found; precision = TP / (TP + FP) counts how much of the reading is useful. Moving the threshold trades one for the other.
  • Choose the metric and target from the application, before training (Goodfellow §11.1): first recall ≥ 98%, then the fewest notes to read. That gives threshold 0.25: 1,440 notes instead of 10,000, at 85.6% coverage.
  • Low precision can be fine: 34% precision means two of every three notes read are false alarms, but the registrars still read 86% fewer notes and miss only 2% of cases.

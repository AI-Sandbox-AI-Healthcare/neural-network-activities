Activity 10.1.1Conv Windows for Sentiment — How Far Can a Filter See?✓ 10.1.1 Completed

A sentiment classifier reads a review as a sequence of words. A 1-D convolutional layer slides each filter over every window of k consecutive words, scores the window, and max-pools to keep the filter's best score in the whole review. Here two already-trained filters — one collecting positive evidence, one negative — decide the label.

Stage 3 — A Recurrent Reader

A recurrent network reads one word at a time and carries a state forward. Below is a hand-set recurrent rule whose state is two numbers — a negation flag n and a running score s. The same rule is applied at every word; a trained RNN learns something similar inside its hidden state.

n(t) = 1 if word t is "wasn't", otherwise n(t−1)
s(t) = s(t−1) + (1 − 2·n(t)) · polarity(word t)   polarity: good +1, happy +2, bad −1, unhappy −2, others 0
label = positive if the final s > 0
Read the longer review to the end.
Takeaway
  • A conv filter only relates words inside one window. A and B need k ≥ 2 ("being bad" vs "being good"); C's negation needs k ≥ 7, and the longer review k ≥ 12: k = last − first + 1.
  • Seeing further costs k × d weights per filter in one layer, or more layers: stacked k = 2 layers see L + 1 words, dilated ones about 2L.
  • A recurrent network applies one rule at every step and carries a state forward, so the same few parameters cover a gap of any length — sharing parameters across time instead of across a window.
  • The catch: learning to carry information over long gaps is hard — gradients must flow back through every step (10.2.2, 10.7, 10.10).

Activity 6.4 Counting Linear Regions of a Deep ReLU Network ✓ 6.4 Completed

For one input (d = 1), each of n ReLU units can add at most one breakpoint inside an existing linear interval. A layer therefore splits each interval into at most n + 1 pieces. With l hidden layers, a simple upper bound is U(n,l) = (n + 1)l. This is a conservative bound, not a claim that every width and depth can attain it. Explore the bound, then compare it with a sampled estimate for a random network on [−3, 3].

Dropout is normally applied to hidden layers, but it may be applied to any units. What would it mean to apply dropout to the input units? Explore image classification, word-based text, and character-level text.

Why Dropout at All?
Prevents co-adaptation
Hidden units can't rely on specific neighbors always being present — each unit must be independently useful.
At inputs: corrupts raw data
Instead of dropping hidden features, you randomly zero out elements of the input itself — forcing the model to work with partial information.
Implicit data augmentation
Randomly masking inputs creates many implicit versions of each training example — the model sees the same sample many different ways.
The Key Question
In a hidden layer, "zeroing a unit" means ignoring a learned feature.

At the input layer, "zeroing a unit" means something domain-specific.

The meaning depends entirely on what each input unit represents — which is different for images, words, and characters.
Domain Explorer
Dropout rate40%
Image classification: Each input unit is one pixel value. Dropping it means that pixel is set to zero during this training step.

This is similar to randomly occluding part of the image — the model must learn to recognize objects even when parts are missing.

Graphs are everywhere: friends in a social network, atoms in a molecule, papers that cite each other. A Graph Convolutional Network (GCN) updates every node using its neighbours: it averages each node's neighbourhood, then applies a learned weight, a bias and an activation. This lesson builds that up on a five-node graph where each node holds one number h.

Stage 3 — The Learned Part: W, b and ReLU

Averaging alone learns nothing. The layer's output is h′ = ReLU(W · average + b), and training tunes W and b. Together they decide which neighbourhoods make a node "fire" (output above 0). Challenge: find W and b so that only node 3 fires.

Stage 5 — Key Properties of GCN
Takeaway
  • A* = A + I stores the graph: row i has a 1 for every neighbour of node i and for node i itself. Edges go both ways, so A* is symmetric.
  • One GCN layer: average each node's row of A*, then h′ = ReLU(W · average + b). W and b are learned and shared by every node.
  • The average ignores order: shuffling which neighbour holds which value changes nothing.
  • Stacking k layers lets information travel k hops — but every layer also smooths, and with many layers all nodes end up alike (over-smoothing).
